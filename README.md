# SCRIPT VAULT

演技ワークショップの題材（本・シーン）をストックするためのWebアプリ。

## 主な機能

- **本棚**: 題材にする本をタイトル・著者・ジャンル・あらすじ・登場人物つきで登録
  - AIまとめ機能: タイトルと著者からあらすじ・登場人物（役柄つき）を自動生成
  - 登場人物ごとに役柄・年齢・性格・関係性などの詳細メモを記録
  - 登録した本の編集・削除（削除時は紐づくシーンも一緒に削除）
  - タイトル・著者・人物名での検索、ジャンル絞り込み
- **シーン**: 演じてみたい場面を本に紐づけて記録
  - ページ数・感情タグ・シーンタグ・個人メモ
  - 📷 カメラでページを撮影 → AIが文字起こしして本文に自動入力
  - 写真は自動圧縮して保存（不要なら文字起こしだけ残して写真を削除可能）
  - 本・感情タグ・キーワードでの絞り込み検索
  - シーンの編集・削除

## 技術構成

- React 18 + Vite
- Firebase Authentication / Cloud Firestore
- Vercel Serverless Functions + Anthropic API（AIまとめ・文字起こし）

## セットアップ

```bash
npm install
npm run dev
```

環境変数（Vercel に設定）:

```
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

## データ保存について

写真は保存前に長辺1000px・JPEGに圧縮され、1枚あたりおよそ100〜300KBで
Firestoreのドキュメント内に保存されます（1ドキュメント1MB制限内）。
Firestore無料枠（1GiB）でも数千枚規模まで保存できますが、
文字起こしだけを残して写真を削除すれば容量はほぼ消費しません。
